NEXUS OSINT

Public Information & Network Analysis Tool

NEXUS OSINT is a lightweight OSINT and network-analysis tool written entirely in Python using only the standard library.

It is designed for educational purposes, public-information research, and analysis of systems you own or are authorized to test.

Features

* 🔎 Public profile availability checks
    * Instagram
    * GitHub
    * Reddit
    * TikTok
    * YouTube
* 🌐 DNS analysis
    * IPv4
    * IPv6
* 🔗 HTTP / HTTPS analysis
    * HTTP status
    * Headers
    * Redirects
    * Final URL
* 🔐 TLS certificate inspection
* 🤖 robots.txt inspection
* 🌍 Public IP detection
* 💻 Local device information
* 📡 Local network information
* 🔢 IP address analysis
* 🔌 TCP connectivity checks
* 📄 Automatic TXT report generation
* ⚡ Parallel public-profile checks
* 🧩 No external Python dependencies

Requirements

Python 3.x

NEXUS OSINT uses only modules included with the Python standard library.

Dependencies

None

Installation

Clone the repository:

git clone https://github.com/rcfjtnvj5p-hub/Nexus-OSINT.git
cd Nexus-OSINT

Run the program:

python nexus.py

Depending on your system, you may need:

python3 nexus.py

Usage

Start NEXUS OSINT and select an analysis from the interactive menu.

The available modules include:

1. Public Profile Check
2. DNS Analysis
3. HTTP / HTTPS Analysis
4. TLS Certificate Analysis
5. robots.txt Analysis
6. Public IP
7. Local Device Information
8. Local Network Information
9. IP Analysis
10. TCP Connectivity Check
11. Full Analysis
12. Save Report

Privacy & Scope

NEXUS OSINT is intentionally limited to information that can be obtained through public sources or from the local environment where the program is running.

It does not attempt to:

* Access private accounts
* Obtain passwords or authentication tokens
* Track a person’s precise private location
* Access Apple ID or other private accounts
* Access another person’s Wi-Fi or Bluetooth information
* Remotely access another person’s device
* Bypass authentication or security controls
* Collect private information without authorization

The tool should only be used against systems, accounts, and networks that you own or have explicit permission to analyze.
